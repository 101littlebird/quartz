少说废话，居然能省87%的token？？？

最近火了个Claude Code Skill 叫Caveman（翻译中文叫史前人类），GitHub上有4k ⭐

一句话概括：让 Claude 像原始人一样说话，只留核心信息，砍掉客套话和废话来省 token

实测数据⬇️

► 10个任务平均省 65% 输出 token

► 最高 87%（解释类任务），最低 22%（代码生成类）

► 三档可选：lite（去废话）、full（去语法）、ultra（电报体）

本质上是个精心调教的 system prompt，打包成了可安装的 skill，技术含量不高但思路确实巧

几个注意点：

► 省的是输出 token，不是输入 token，你喂给 Claude 的代码上下文该多大还是多大

► ultra 模式下回复可读性会变差，适合你本身就懂这块只要结论的场景

► 其实你在 CLAUDE.md 里加一句「回答简洁不要废话」也能达到类似效果，只是没这么极致

对重度 API 用户来说每天能省几刀，对普通用户来说，在rule里写句「简洁回答」可能就够了...

►个人感觉最大价值不是省钱，是省注意力

很多人反馈真正的收益是：扫一眼就能抓到关键信息，不用在一堆客套话里找答案，有人说 caveman 模式反而更容易理解了

最后，中文语法本身就没有 a/an/the 这些冠词，天然比英文省 30-40% token，所以这个skill对中文用户的边际收益可能更小，模型默认的啰嗦是为了讨好人类，不是为了效率...
