去年一整年，我没投过一分钱广告，没做过一条爆款视频，纯靠线下沙龙一场一场地磨，从零做到了第一个六位数订单。今天把这套打法完整拆解给你。

我之所以愿意全盘托出，是因为我已经完成了线下阶段的验证——客户需求是真实的，解决方案是跑通的。2026 年我给自己定了一个硬目标：必须把线上打开。为了不让线下成为路径依赖，我选择把所有经验分享出来。一旦有人做得比我更好，我就更没有退路了。

看完这篇文章，你也能在自己的城市复制这套打法。

省流版：

线下社群的核心需求不是"学习"，而是"链接"→ 帮参与者找到客户，你才能走得长远

用 AI 搭建社群人脉匹配智能体 → 把参与者信息变成可查询的知识库，自动撮合链接

用 Obsidian + Claude Code 构建个人 CRM → 用知识图谱管理所有客户关系

分享内容从飞书文档 + 手把手实操起步 → 后期再过渡到幻灯片演讲

心态：你在讲台上的那一刻，你就是最牛的 → 任何来的人，都是你吹牛的资本

获客渠道：知识星球同城群 + 小红书本地搜索 + 活动小程序

下面逐步拆解。

一、线下社群的底层需求：不是学习，是链接

先问一个问题：你参加各种社群、线下聚会，真正的目的是什么？

如果只用一个词总结，我的答案是——链接。

马克思说"人是一切社会关系的总和"。费孝通在《乡土中国》里提出了"差序格局"——不是以一个人为中心向外扩散的单一圆环，而是每一个节点上的人都是一个新的圆环，不断向外辐射。

最简单的例子： 我因为认识了 S 哥，就不止认识他一个人，而是能接触到他整个社群里的每一位优秀朋友。这种链接不是一对一的，而是一对多的。

这个链接再往深层挖，我发现分两种：

第一种，情绪价值。 这部分人的需求与解决方案我还在验证，暂不展开。

第二种，找客户。 这才是线下社群最核心的驱动力。大部分人参加线下活动，不是为了认识一个人而认识一个人，而是希望通过认识这个人产生成交、产生转化。

赚想赚钱的人的钱，是最好赚的。

线下社群里都有谁？卖创始人 IP 打造的，卖 AI 课的，卖智能体定制的，卖咨询的，卖形象设计的，甚至卖珠宝、算卦的都有。他们都是带着明确目的来找客户的。

这意味着什么？你的分享内容是次要的。 不要觉得你的分享是主场、是核心——参与者报名的真正目的，排在分享之上的，是链接和找客户。

甚至作为组织者，你还需要主动帮助他们完成链接、撮合合作。只有这样，你的活动才能走得长远。

具体怎么做？让每个参与者在活动前就在群里完成自我介绍。只有这样，大家才能带着目的精准找到该链接的人，你也能知道可以帮哪两个人牵线搭桥。

二、AI 落地场景一：社群人脉匹配智能体

前期你可能不知道怎么撮合两个人的链接，没关系——我们搞 AI 的，就用 AI 来解决。

场景还原：

很多付费社群会让你填一个飞书多维表格的表单，里面是所有成员的基础信息。但权限往往不允许你全部复制下载。

我的做法：在闲鱼上找人破解多维表格权限，创建一份有权限的副本，导出完整的 Excel。然后用 RPA 把 Excel 逐行转化为 Markdown 文件——因为 AI 处理 Markdown 的效果远优于 Excel。

有了这份 Markdown 知识库，我封装了一个智能体：

成员可以查询自己的自我介绍是否录入

描述找客户的需求，智能体基于知识库告诉他该链接谁

输入一个具体人名，智能体帮你分析怎么基于你的产品完成转化，还能给出私聊话术和添加方式建议

我拿着这个智能体去找社群负责人。他的第一反应是：不允许我把这个智能体给别人。 然后当场转了 2000 块钱，要求这个智能体只在他们社群内部使用。

这个场景可以复制到任何社群——别人的社群，你自己的社群，都能做。

三、AI 落地场景二：用 Obsidian + Claude Code 搭建个人 CRM

Obsidian 的核心能力是两个：记笔记 + 创建笔记之间的双向链接，所有链接最终形成知识图谱。

换个思路：如果你放进去的不是知识，而是每一个联系人呢？

那你就拥有了一份属于自己的客户关系管理系统。知识图谱里放的是你所有的客户、所有的朋友，每个人之间都有链接关系。

具体操作：

让参与者按统一格式发自我介绍到群里：我是谁、经历是什么、能提供什么、需要什么

批量导出，放进 Obsidian

用 Claude Code 为每个人创建独立文档

再让 Claude Code 基于每个人的需求，自动创建人与人之间的双链

这样你就能通过知识图谱可视化地看到：A 可以和谁链接，A 和 C 之间可以通过 B 产生链接。一份完整的关系网就建起来了。

现在有了 Claude Code，这套系统比去年更容易实现。加上手机端调用 OpenClaw ，你可以随时随地补充和完善你的 CRM。

我的一个朋友拿着这套系统，去年跑了一圈全国市场，回来直接给我打了将近 5000 块钱。效果是实打实的。

由此，我们就解决了社群成员中链接的问题。接下来，就该我们正式进入到线下分享阶段。

四、分享内容：从 60 分开始，照样降维打击

很多人觉得分享内容很难。其实你高估了线下听众的水平。

因为可得性偏差在起作用。 你每天刷推特、看北上广深的前沿玩法，会觉得大家都很厉害。但当你真正去线下组织活动时，你会发现：他们连 Obsidian 是什么都没听过，Claude Code 是什么都不知道，哪怕养龙虾这么火，他们也不清楚具体能干什么。

你的 60 分，对 30 分的人来说就是降维打击。算法也是这个逻辑——它会把你 60 分的内容推给 30 分的人，而不是 90 分的人。

分享形式的进化路径

第一阶段：飞书文档 + 手把手实操

前期不要想太多。不需要做 PPT，不需要讲认知。列一个飞书文档框架，放上网站链接，然后手把手带着大家实操。跑通两遍就能上台讲了，遇到问题随机应变。

为什么这么有效？因为市面上讲 PPT、讲认知的人太多了，他们真正需要的是有人手把手领着做。 前期靠这个可以快速打响名声。

第二阶段：幻灯片 + 适度实操

人越来越多之后，你不可能带所有人手把手操作了。

这也是所有做知识付费人所存在的困境。即前期你分享的内容可以很干很干，但随着用户逐渐增多之后，你的干货对于他们而言可能是天书，所以就必须降低难度了。所以大家还是要珍惜如今的我。

回归主题，因为我们没有办法保证在大厂里边让所有人都能够实操会，所以此时要加入认知层面的内容了，开始用幻灯片。讲幻灯片能训练表达能力，也不会把你局限在"技术老师"的定位上。

一个忠告：前期不要用 AI 生成幻灯片。 我见过太多人用 NotebookLM 生成的幻灯片去线下讲课，结果要么全程念稿，念到错别字自己都不认识；要么翻到某一页说"这页不对，下一页"——观众体感极差。

NotebookLM 的信息图适合总结，不适合分享。所有信息一次性铺开，观众注意力是分散的，你没办法引导节奏。手搓幻灯片的过程本身就是梳理内容的过程。

五、心态：你在讲台上的那一刻，就是最牛的

大家前期出来做分享，最担心的问题是，我分享的内容，观众是不是都会呀？会不会被人砸场子呀？

保证会有比你厉害的人来听你的分享。但是没关系。

我的老大哥跟我说过一句话：你不能太客气，不能做老好人。你在讲课的那个瞬间，你就是最牛的。

我自己总结了一句话：

来的任何一个人，都不能阻挡你的牛逼，只能成为你吹牛逼的资本。

举个真实的例子：我第一场分享，20 个人，一个下午的时间，让不同年龄段的参与者——从完全不懂电脑的小白——搭建出了一套批量抓取小红书笔记并二创的工作流。

分享结束后，一位湖南省省厅的教授拉着我的手说，有一个 2 亿的数字分身项目，非要拉我一起做。这个项目后来因为种种原因没有推进，但一个省厅教授出现在我的第一场分享里——这就是我现在吹牛的资本。

他在别的地方可以很厉害，但他坐在台下听你讲的那一刻，你就是全场最牛的。心态对了，分享内容的问题就解决了大半。

六、销售转化：找到属于你自己的体系

这个环节我踩过大坑。

前期我的合作伙伴教了我一套销售转化体系，但不适合我。因为我的分享风格是全程真诚输出，不留钩子，不埋伏笔。到最后突然切换成销售模式，用户的反差感很大，防备心一下就上来了。 转化做得很僵硬。

后来我想明白了：我更擅长手把手陪跑，而不是现场逼单。我甚至需要反向筛选客户—— 前期我还没有很大起色的时候，愿意投资我的人本身就眼光不错，我也愿意陪他一起走。

销售转化没有标准答案，你需要在实践中找到属于自己的那套体系。

七、获客渠道：三个入口解决前期客源

第一，知识星球 / 付费社群的同城群

你加的各种付费社群，基本都有同城群。前期放低姿态，把想法和计划跟同城负责人聊清楚，他们愿意扶持你、帮你做宣发。先参加几场别人组织的活动，摸清流程，然后自己申请组织。

第二，小红书本地搜索

搜索"你的城市名 + AI / 线下活动"等关键词，就能找到本地的线下社群。先参加，再链接社群主理人。前期可以免费给他做几场分享，跑通之后再谈分成。

第三，活动小程序

不同城市有不同的本地活动平台，比如长沙有"粗门""取伙"。门槛很低，不需要前期费用，成交后平台抽成即可。你可以参考其他城市的活动形式，同步到自己的城市。

基本上这三个渠道就能解决前期客源问题。

最后

有学员问我：长沙这么多讲 AI 课的老师，你这么年轻不会有压力吗？

我笑了一下，跟他说：没有对手，也没有压力。

拿着线上最前沿的玩法，拿着顶级社群里对流量的理解，你在同城里很难遇到真正的对手。只要你的价值观是正的，能站着赚钱，能真正给对方提供解决方案——在你的城市里，你不会有对手，只有时间长短的问题。

这个赛道看似拥挤，其实很开阔。与其纠结蛋糕怎么分，不如想办法携手把蛋糕做大。

我是观自，专注 AI 赋能培训与智能体定制服务。这套线下打法，你在任何城市都可以跑通。如果你跑通了，记得告诉我一声，发个红包，我们一起庆祝。
