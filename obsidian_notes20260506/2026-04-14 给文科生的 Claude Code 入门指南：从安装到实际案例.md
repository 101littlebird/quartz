想试试？先得把它装上。

一行命令安装成功

不需要装 Node.js，不需要懂终端。就一行命令。

Mac 用户，打开终端，粘贴这个：

bashcurl -fsSL https://claude.ai/install.sh | bash

完事了。

Windows 用户，两种方式。

省心的：打开 PowerShell，粘贴这个：

bashwinget install Anthropic.ClaudeCode

或者用官方安装脚本：

bashirm https://claude.ai/install.ps1 | iex

都行，选一个就好。

Windows 用户，注意了——有两个坑。

1. 你得先装 Git for Windows。去 git-scm.com 下载，装的时候勾上"Add to PATH"。不装这个，Claude Code 跑不起来。

2. PowerShell 和 CMD 别搞混。

装完了验证一下：

claude --version

出来版本号就说明装好了。没出来的话，关掉终端重新打开再试一次。

装好了。接下来要解决一个问题：怎么让它跑起来。

两条路

装好了，打开它输入 claude，这时你面前有两条路。

官方订阅，或者用 API Key。一个省事，一个省钱。

方法一：iOS 内购（推荐新手）

美区 Apple ID → 支付宝买礼品卡充进去 → iPhone 下载 Claude App → App 内订阅 Pro（$20/月）。

苹果抽 30%，贵一点，但最稳，不容易被封。

方法二：虚拟卡 / 海外银行卡

有海外银行卡直接刷。我自己开了美国公司，用空中云汇的卡，没问题。虚拟卡风险高，WildCard 去年停了，不推荐新手。

方法三：国产方案（不翻墙）

国产服务商套了 Claude Code 的接口，不是真 Claude，但体验差不多，国内直连。

配置就设两个环境变量，去官网注册拿 Key 填进去就行：

bashANTHROPIC_BASE_URL=服务商的地址 ANTHROPIC_AUTH_TOKEN=你的 API Key

防封提醒（官方订阅用户必看）： IP 固定别老换、一人一机一节点、新号先稳 24 小时再付费、注册用 Gmail 别用 Outlook。

搞定了。不管你选了哪条路，现在应该已经登录成功了。

光标在闪

登录成功，光标在闪。

然后呢？

大多数人在这一步卡住了。不知道说什么，随便打了句"你好"，得到一段废话，然后就觉得"也不过如此"。

别这样。第一句话，试试这个：

帮我写一个简单的网页，内容是我的个人介绍，标题叫"关于我"

然后看着它干活。它会自己创建文件、写代码、把网页搭好。你什么都不用做。

完事之后，打开它生成的文件，浏览器里就能看到一个真实的网页——你的个人介绍页。

这东西真的在帮你做东西，不是在瞎编。

跑通了第一次。

再教你三个技巧，以后会用得很顺。

第一个，回退。

说错了？双击 Esc。它会退回到你上一步的状态。不用怕说错话，随时能撤。

第二个，上下文管理。

聊久了你会发现它变慢了，或者开始犯傻。这是上下文太长了。两个命令：

/compact — 压缩上下文，保留重点，扔掉废话。 /clear — 全部清空，重新来。

觉得它不对劲了，先试 /compact。还不行就 /clear。

第三个，语音输入。

跟 AI 对话，说比打字快得多。装个 typeless 或者豆包的语音输入，对着它说话就行。

你会发现用嘴比用手效率高太多了。

到这里，你已经装好了 Claude Code，完成了第一次对话，还学会了三个核心操作。

如果你看到了这里，说明你是认真的。
