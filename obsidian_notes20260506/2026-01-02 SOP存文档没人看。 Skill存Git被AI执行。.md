SOP存文档没人看。 Skill存Git被AI执行。

这是我最近想通并要求团队执行的一件事：

Team Skill = 把最强员工的工作方式，一秒同步给所有人。 不是培训，不是文档，是 git pull。

-----------

传统团队的问题： 10个人用10种方法解决同一个问题，各自为战。

Team Skill的做法：

1个人找到最优解 → 写成Skill → push → 10个人都用最优解。

核心公式：Claude Code + Git = 团队能力倍增器

Claude Code：秒建Skill + 确保执行

Git：光速共享 + 版本迭代

所以不管是技术还是非技术同事，Claude Code和Git都必须学会使用

------------

每个团队都需要一个 Skill Manager。

他不是写文档的，他是管理「企业大脑」的：

- 鼓励同事把SOP变成Skill

- Review并merge好的Skill

- 确保Skill被执行，而不是被遗忘

起步阶段，负责人自己当。 因为只有你最清楚团队需要什么能力。

企业大脑不是一个人建的， 是每个员工贡献一个神经元。
