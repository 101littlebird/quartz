但是去年他们来了个人给我们讲大模型，尬得全会场都要扣脚趾头，那会我们内部已经有一小部分人开始用 Claude code 了，我们主要的问题是业务问题

结果来的人给我们讲大模型训练，关键是这个人自己也不是搞大模型训练而是搞搞 tomcat，没想到摇身一变就被阿里云的销售包装成大模型专家出来忽悠
