天哪…纽约大学、斯坦福和凯斯西储大学的教授停止手工构建课程。

他们用NotebookLM几小时内完成，一位教授称之为学术研究20年来最大转变。

以下是他们公开分享的确切工作流程：

第一步 - 改变一切的资源上传策略。

大多数人上传一两份文档。

构建完整课程的教授一次上传整个阅读清单。

免费版最多50个资源，每个资源50万字。

PDF、Google文档、网址、YouTube讲座、音频和带OCR的图片。

一个笔记本=一个课程单元。

Stanford教师公开记录的工作流程:

→ 上传单元的所有指定阅读材料

→ 上传课程大纲

→ 上传往年考题

→ 上传相关原始资源

NotebookLM现有100万token上下文窗口。

它可同时理解整个单元并跨越所有内容进行推理。

市场上没有AI以您的具体资源为基础做到这一点。

第二步 - 课程映射提示。

资源上传后，教授运行的第一个提示:

'基于所有上传的资料，为本单元创建完整课程地图。确定学生必须理解的5个核心概念。对于每个概念，列出:引入它的资源、深化它的资源、挑战或复杂化它的资源。然后建议逻辑教学顺序。'

返回的是整个单元的结构化路线图，每个声明都引用到确切的上传资源。

纽约大学副院长用这个版本识别了整个修订课程中的课程等效性。

以前需要数周跨部门手动交叉参考的工作在一次会话中完成。

第三步 - 生成课程计划。

课程地图之后，教授运行:

'使用上传的大纲和课程材料，为[主题]创建详细的日程课程计划。每堂课应包括:学习目标、关键概念、一个现实示例或类比、讨论问题、60分钟课程的时间分解。'

NotebookLM生成完全基于上传材料的完整计划。

没有幻觉引用，没有捏造的例子。

它生成的所有内容都可追溯到您可以点击验证的来源。

ASU教职工文档记录使用完全相同的方法组织学术文章并识别跨学科主题。

第四步 - 学生学习材料工作流程。

这是NotebookLM每周为教授节省最多时间的地方。

构建课程计划后，他们从同一笔记本生成整个学生学习包:

→ 带有主要观点、关键论点和支持证据的学习指南

→ 基于确切课程材料的阅读理解问题

→ 关键概念和术语的闪卡 - 自动生成、引用资源

→ 练习测验 - 多选或短答，答案密钥引用阅读

东北大学讲师文档记录学生使用完全相同的工作流程从课程阅读创建自己的自定义学习辅助工具。

第五步 - 学生预习的音频概览。

这是教授开始分享后在学生中走红的功能。

每堂课前，教授生成该周阅读的音频概览。

学生获得一个10-15分钟的播客风格摘要 - 两个AI主持人解释材料、建立联系、使用类比 - 在他们读一页之前。

凯斯西储大学教职工文档记录使用它来帮助学生处理他们原本会完全避免的密集阅读。

结果:学生到课堂时已经接触到关键思想。

课堂时间从'让我解释阅读内容'转变为实际讨论、应用和辩论。

第六步 - 用于文献综述的深度研究升级。

这是改变研究教师的功能。

NotebookLM上的深度研究让工具自主搜索网络、构建参考书目、编译完全引用的研究报告。

一位匹兹堡大学研究员文档记录使用它将文献综述准备时间减少70%。

工作流程:

→ 上传现有资源和研究问题

→ 运行深度研究

→ NotebookLM规划自己的网络搜索、确定当前资源的差距、提取新论文、综合所有内容

Walter Isaacson用NotebookLM分析Marie Curie的日记。

第七步 - Google课堂集成以与学生共享。

这是为教师关闭循环的2026年更新。

您现在可以直接从Google课堂创建NotebookLM笔记本。

一键拉入已分配给学生的所有资源。

无需手动重新上传，无需在新工具中重建课程。

将笔记本分配给学生为'仅查看' - 他们获得基于您分配给他们的确切材料的完整AI辅助体验。

学生可以查询笔记本、生成自己的学习指南、运行自己的音频概览、创建闪卡。

完整教授工作流程 - 保存此内容。

以下是纽约大学、斯坦福、凯斯西储、亚利桑那州立和东北大学教职工记录的完整堆栈:

第1步 → 将整个阅读清单+大纲+往年考试上传到每个单元的一个笔记本

第2步 → 运行课程映射提示 获取带有引用的完整教学顺序

第3步 → 为每堂课生成日程课程计划

第4步 → 一键生成学生学习包 学习指南、闪卡、测验

第5步 → 为每堂课前的学生预读创建音频概览

第6步 → 使用深度研究运行文献综述和识别资源差距

第7步 → 通过Google课堂共享笔记本 学生与同一资源库交互

过去需要整个暑假的工作现在需要一周。

过去需要一周的工作现在需要下午。

大学系统已在同一课程构建流程上运行了几十年。

上传阅读材料。撰写讲座。构建评估。每学期重复。

NotebookLM没有改变教授教的内容。

它改变了隐形工作花费的时间。

花费3个月的文献综述。

花费2周的课程计划堆栈。

花费一个周末的学习材料。

这仍然是教授的智力工作。

NotebookLM只是移除了您在晚上11点手动交叉参考50个PDF的部分。

在此方面进展最快的机构不是在取代教职工。
