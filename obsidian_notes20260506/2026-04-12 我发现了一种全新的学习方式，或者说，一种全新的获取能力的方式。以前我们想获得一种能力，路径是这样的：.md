我发现了一种全新的学习方式，或者说，一种全新的"获取能力"的方式。以前我们想获得一种能力，路径是这样的：

找到别人的代码 → 读代码 → 理解原理 → 自己重写或改写 → 变成自己的能力

这条路很长，成本很高。一个优秀的开源项目，你要真正理解它的设计思想，可能需要几天甚至几周。现在的路径变成了：

找到别人的代码 → 让 AI 读 → AI 提炼成 Skill → 你拥有了这个能力

从几天缩短到几十分钟。而且这种方式有复利效应。

每多一个 Skill，你的 AI 就多一种能力。下一次遇到类似的任务，AI 自动调用这个 Skill，效率更高。然后你又能在新的任务中发现新的知识，提炼出新的 Skill。

你的个人飞轮：知识输入 → Skill 提炼 → AI 更强 → 更高效产出 → 更多知识输入。

所以我说：在 AI 时代，Markdown 比 Code 值钱。

因为 Markdown 承载的是你的想法和经验，而 Code 只是 AI 烧 Token 产出的副产品。

对于有经验的人来说——不管你是程序员、产品经理、运营、设计师——这个时代其实是好消息。你积累了十年二十年的行业经验、踩过的坑、建立的直觉，这些东西在 AI 时代不但没有贬值，反而成了最稀缺的资源。

AI 放大的是你已有的能力。你知道得越多，AI 就帮你做得越多。
