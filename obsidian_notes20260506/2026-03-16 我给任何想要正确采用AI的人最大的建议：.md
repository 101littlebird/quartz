我给任何想要正确采用AI的人最大的建议：

1. 花点钱订阅Anthropic

2. 下载Claude Code

3. 打开Claude Code

4. 按'Shift-Tab'直到显示'plan mode on'

5. 打开iPhone的语音备忘录。讲述你想完成的所有事情。

想好了就继续说，至少10分钟，越长越好

6. 将语音备忘录发送到电脑

7. 下载MacWhisper转录语音备忘录。相信我，你以后会经常用到它

8. 在Claude Code中输入：'我以前从未用过你，但我讲了一些内容。

我会粘贴在下面。请阅读并提问帮我理解如何使用你。继续提问直到我说完为止'

9. 粘贴转录内容

10. 按回车
